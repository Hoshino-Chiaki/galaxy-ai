# 实时时间工具

`time.now` 属于 `time` 分类，通过现有 `galaxy_cli` 入口执行。命令为 `galaxy-cli time now`；可选 `--input '{"timezone":"UTC"}'`，默认时区 `Asia/Shanghai`。

输出仅包含：

| 字段 | 含义 |
| --- | --- |
| timestamp_ms | Unix 毫秒整数 |
| datetime | 含 UTC 偏移、三位毫秒的 ISO 8601 时间 |
| timezone | 使用的 IANA 时区名称 |
| today | 该时区今天的 YYYY-MM-DD 日期 |
| yesterday | 该时区昨天的 YYYY-MM-DD 日期 |

所有字段来自调用瞬间同一次系统时钟采样；用整数处理纳秒到毫秒的转换，避免浮点舍入改变毫秒。昨天按当地日历计算，兼容夏令时跨日。业务需要 YYYYMMDD 时移除日期连字符后转换为整数即可。工具描述提示 AI 在处理相对日期时调用，不根据历史对话推断日期。

服务端网关仅识别固定命令及可选时区参数，校验当前登录与 `workspace:read`，调用前后检查权限，记录调用审计；不请求有赞或飞书凭证，不开放 shell、系统设置或设置时间能力。默认业务输出保持五个字段，无额外版本包装。

CLI 工具为独立模块 `galaxy-cli/src/galaxy_cli/tools/time/now.py`，网关解析在 `backend/xingxu/time_tools.py`。注册表自动发现分类和工具，控制台工具列表沿用 help 自动生成栏目，不修改全局提示词。本次只增加实时时间，不扩展员工名单或考勤范围。

本地仅编辑源码；运行、测试和部署均在服务器进行。服务器已启用 NTP 同步。部署不修改员工凭证、AI 配置或客户端安装包。
