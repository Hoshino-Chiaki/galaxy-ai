# Galaxy AI 输出展示（0.4.2）

普通助手回复使用 Streamdown 渲染 Markdown，支持标题、列表、表格、引用、代码高亮和复制原始回复。通过独立 CSS 适配现有深色界面，无需迁移整个聊天框或引入另一套 UI 框架。当前接口仍在整轮完成后返回，接入渲染器本身不改变服务端传输方式。

按用户要求，已移除自动报表指标卡、图表、选择与对比界面，不再根据报表工具结果自动插入展示。普通回复中的 Markdown 表格正常渲染；完整原始工具结果仍在工具记录中展开，Excel/文件下载卡片继续保留。经营报表查询工具本身不受影响。

先前追加到全局提示词的自动报表展示说明已撤回，仅移除完全匹配的原段落，其他提示词保留。变更前备份在 backend/private/prompt-backups，不进安装包。

全局提示词仅保留助手身份、时间变量和通用行为原则，不写工具描述、业务字段、解析口径或调用流程。经营报表的当日与昨日统计口径归 youzan.business-report 的 DESCRIPTION；生成文件与下载托管流程归 excel.create 和 file.publish 的 DESCRIPTION，通过 help 获取。backend/verify-file-publish.py 已移除自动追加全局提示词的逻辑，并在验证结束时检查全局提示词未变化。服务器仅更新这两处工具 DESCRIPTION，未部署暂停中的商品相关改动；控制台 help 已确认最新说明生效。本次无需重装客户端。

Markdown 禁用原始 HTML，不自动请求外部图片。用户点击 HTTP/HTTPS 链接时，经主进程校验后用系统浏览器打开；文件路径及其他协议不通过此通道打开。代码仅展示，不执行。原有下载卡片继续走带身份校验的下载功能。

本次不恢复商品工具、商品搜索及店铺会话改造，不部署本地待完成的后端改动，不刷新或替换有赞凭证。本地后端继续停止。旧会话可以直接使用新的显示组件。
