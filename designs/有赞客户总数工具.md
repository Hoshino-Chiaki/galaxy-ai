# 有赞客户总数

工具名：`youzan.customer-count`，分类：`youzan`，命令：`galaxy-cli youzan customer-count`。实现独立放在 `galaxy-cli/src/galaxy_cli/tools/youzan/customer_count.py`。

业务输入为空对象 `{}`，可省略 `--input`；不接受筛选、分页、店铺 ID 或凭证。店铺范围沿用网关参数：

```json
{"args":["youzan","customer-count"],"shops":"all"}
```

`shops="all"` 查询当前连接账号全部授权店铺，`"current"` 查询默认店铺，数组指定店铺 ID 或名称。自然语言请求“获取每个店铺客户总数”由 AI 发现工具后调用，不需要修改全局提示词。

工具每店仅请求客户列表第一页 1 条，从接口 `data.total` 读取总数。单店输出只有：

```json
{"total":104027}
```

多店输出沿用现有格式：

```json
{"shops":[{"kdt_id":"店铺ID","shop_name":"店铺名称","data":{"total":104027}}],"partial":false}
```

结果是当前账号在各店可见的客户数量，不返回客户姓名、手机号、客户明细或其他业务字段，不遍历所有客户。只接受有效非负整数；缺失总数、权限不足、登录失效和接口失败均报错，不将这些情况视为 0。某店失败时该项为 error，并设置 partial=true，其余店铺仍独立返回结果。总部与分店可能有客户重叠，不直接求和为跨店去重人数。

权限复用 `youzan:customer:read`，仍须有 `tools:galaxy_cli`，使用各用户自己的连接和授权店铺。继续执行“进入目标店铺 → 刷新该店凭证 → 立即查询”，同 SID 的操作互斥。支持已适配的零售、微商城和 CRM 客户列表版本。

工具注册后，help、有赞分类工具列表、分类提示词中的工具数量自动更新，无须修改客户端或全局提示词。云端验证脚本：`backend/verify-customer-count-live.py`，只验证店铺和数量，测试对话完成后删除。
