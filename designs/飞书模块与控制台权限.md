# 飞书模块与控制台权限

0.7.0 已扩展为 20 个业务域、669 个操作；原 4 个便捷工具兼容保留。读写范围、分组授权和当前实现见《飞书全业务接入.md》。本文下文保留 0.6.0 初版接入记录。

控制台分为“有赞”和“飞书”，员工可管理各自连接；“AI 设置”是独立的管理员板块，包括 AI 模型、全局提示词、工具列表和工具分类提示词。服务端仍限制 AI 配置接口，隐藏按钮不是唯一的权限判断。

## 飞书授权

按已确认的方案：管理员配置一个企业自建应用，员工通过官方 OAuth 各自绑定飞书账号。

1. 管理员到“控制台 → 飞书”，填写 App ID、App Secret。
2. 在飞书开放平台给应用开通页面列出的只读 scopes，按企业流程发布和审批。
3. 员工打开同一页面，点击“授权连接”，在飞书官方页面同意授权。
4. 客户端按飞书要求的间隔查询授权结果。无需配置本服务的 OAuth 回调域名或新开公网端口。

设备授权、token 刷新使用与官方 CLI 对应的 `accounts.feishu.cn` 端点；获取身份使用官方 `authen/v1/user_info`。只接受官方 HTTPS 授权链接，不把 device_code 传给前端或 AI。

目前没有提供真实企业应用凭证，服务器应用尚未配置。已完成官方 CLI dry-run、模拟 OAuth 设备授权/轮询/刷新和真实服务的管理员/员工权限检查；真实飞书文档内容读取须在配置和授权后验证，不能声称已读通用户资料。

## 目录和运行

- `backend/xingxu/feishu/`：共享应用、员工 OAuth、刷新、管理 API 和网关命令校验。
- `backend/feishu/cli/`：基于官方扩展的 Go wrapper、固定版本构建脚本和许可证。
- `backend/feishu/bin/lark-cli`：只在服务端运行的 CLI。
- `galaxy-cli/src/galaxy_cli/tools/feishu/`：四个独立 Python 工具。
- `galaxy-cli/src/galaxy_cli/feishu_client.py`：固定命令映射、私有 stdin、完整 JSON 和受控下载。

CLI 按每次调用从服务端接收当前员工的短期 token。App Secret、refresh token 留在服务端，不写命令参数、环境变量或模型上下文。没有把所有员工登录写到同一个 CLI HOME 或默认账号中。

## 工具

- `feishu.search`：关键词搜索；query 最多 30 字，可按 page_size/page_token 翻页。
- `feishu.document-get`：读取 docx/wiki 正文，支持目录、关键词、章节范围，输出完整官方 JSON。
- `feishu.folder-list`：列文件夹直接子项，不递归，支持分页。
- `feishu.file-download`：下载云空间普通文件到当前员工工作区；输入 file 和 filename，输出真实 path/filename/size，可交给 file.publish。下载并不代表已经解析二进制正文；PDF、Word、Excel 等的内容分析仍需要对应解析工具。在线文档不按普通文件下载处理。

模型入口仍只有 galaxy_cli。help 和工具列表自动增加 feishu 分类，飞书分类提示词默认空白，全局提示词没有增加飞书或工具说明。

## 隔离和权限

`feishu.json` 中共享应用按 workspace_id 保存；个人连接按工作空间与 Galaxy 用户 ID 的哈希保存，并绑定应用配置版本和飞书身份。App Secret、设备码、访问 token 与刷新 token 均加密存储，外部接口只返回状态、公开应用 ID、当前员工身份和授权 URL。

应用更换会使旧员工授权失效，需重新授权；重新授权只替换该员工自己的凭证。断开连接删除该员工本地授权记录，其他成员不受影响。断开不是取消飞书中已经批准的应用授权，需彻底撤回时由用户在飞书中撤回。

员工获得 youzan:configure、feishu:configure、feishu:read；飞书企业应用配置只允许 feishu:app:configure（管理员）。有赞仍按工作空间、员工和店铺隔离；不能因开放控制台就使用管理员已有 SID。

文件只写服务器选定的当前账号工作区，不接受任意路径、本地文件引用或外部 URL。CLI 返回后再次检查登录权限与授权是否改变；如果断开或换应用，中途结果不向模型返回。文件发布和下载继续走原有所属用户/工作空间/对话权限。
