# 飞书只读接入调查

官方项目：[larksuite/cli](https://github.com/larksuite/cli)，npm 包 `@larksuite/cli`，执行程序 `lark-cli`，MIT 协议，支持飞书及 Lark。此文档为初始接入调查，当前已实现与部署；实施方式和待配置事项见《飞书模块与控制台权限.md》。尚未创建真实企业应用或请求用户飞书授权。

## 官方能力

- [云文档读取](https://github.com/larksuite/cli/blob/main/skills/lark-doc/references/lark-doc-fetch.md)：`lark-cli docs +fetch --doc "文档URL或token" --doc-format markdown --as user`，支持 docx、wiki，可按目录、章节、关键词局部读取。
- [资源搜索](https://github.com/larksuite/cli/blob/main/skills/lark-drive/references/lark-drive-search.md)：`lark-cli drive +search --query "关键词" --as user`，搜索文档、知识库及云空间对象，结果需按实际分页和权限解析。
- [文件下载](https://github.com/larksuite/cli/blob/main/skills/lark-drive/references/lark-drive-download.md)：`lark-cli drive +download --url "文件URL" --output ./imports/filename --as user`。云空间普通文件下载和在线文档导出是不同操作，docx/sheet 等在线对象应使用相应读取或导出能力。
- 飞书电子表格和多维表格有各自的表内读取命令；不能只读文档正文就假定内嵌表格数据已完整获取。普通 PDF、Word、Excel 等二进制文件还需要本地解析，扫描 PDF 可能需要 OCR。

上述为官方命令示意，实际接入应固定 CLI 版本，核对该版本 help/schema 和 scopes。

## 建议接入 Galaxy AI

维持唯一模型工具 `galaxy_cli`，增加 `feishu` 分类。命令入口由我们的服务端映射为固定 lark-cli 子命令，逐个开放，不向模型提供任意 `lark-cli api`、shell、配置修改和授权管理执行能力。首批可设计：`feishu.search`、`feishu.document-get`、`feishu.folder-list`、`feishu.file-download`，后续按需要增加 sheet/base 读取。

后端新增 `xingxu/feishu/`：授权与刷新、员工凭证隔离、资源链接解析、只读命令映射、结果解析。可复用公共进程通信、文件工作区和审计；飞书正常使用官方 OAuth/API，不需要套用有赞的浏览器登录或切店逻辑。

[官方企业嵌入扩展](https://github.com/larksuite/cli/tree/main/extension)支持自定义 credential provider、命令限制和审计，可用 wrapper main 构建专用二进制，对接服务端加密存储，不依赖全服务器共用的默认 CLI 登录目录。实施时需验证该版本 token 刷新和存储回写契约；不能默认所有用户共用 HOME 或凭证文件。

## 授权方式

官方[云文档概述](https://open.feishu.cn/document/server-docs/docs/docs-overview?lang=zh-CN)区分应用身份 `tenant_access_token` 和用户身份 `user_access_token`。

- 员工自己的资料：员工完成飞书 OAuth 后，按 Galaxy AI 工作空间、员工 ID、飞书租户和用户 ID 绑定凭证；只能在应用已授权 scope 且该用户有资源访问权限的范围内读取。不能回退到管理员的飞书身份。
- 指定企业共享资料：应用身份访问应用自有资源，访问其他人的资料需给予应用对应资源访问权限；不能认为应用 token 自动拥有企业全部文档。

管理员配置 App ID/App Secret，开通所需只读 scopes，并按企业流程发布/审批；员工通过界面点击授权，浏览器/飞书完成同意后，由服务端保存及按官方流程刷新 token，失效或撤销时重新授权。不要让 AI 读取、展示或导出 token。

下载路径由服务器限制在员工工作目录内，模型只能指定资源和受控相对文件名。需要用户下载附件时沿用 file.publish；下载成功与内容解析成功分别返回状态。文件和文档正文是外部数据，不是可执行工具指令。

分类共用注意事项放在“工具提示词 → feishu”，具体输入输出写入每个工具描述，不修改全局提示词。
