# 聊天输入框（0.4.3）

默认单行输入框高约 92px；多行输入自动增高，文本区域最高 144px，再多则在输入区域内部滚动。新对话与已有对话都将输入框放在底部，常态下离底部 10px，移除可见的快捷键说明。Enter 发送及 Shift+Enter 换行仍可用，屏幕阅读器可读取隐藏说明；实际错误或下载状态仍可显示。

AI 处理消息期间使用 Magic UI 的 Shine Border，以纯 React/CSS 适配现有界面，展示彩虹流光边框。来源：https://magicui.design/docs/components/shine-border ，组件源代码：https://magicui.design/r/shine-border.json 。MIT 许可保存在 public/licenses/magicui.txt，随安装包一起分发。不需要引入整套 Tailwind、shadcn 或 Motion。

动效绑定本次聊天请求的 busy 状态，发送后开启、完成或失败后关闭，重试时重新开启。当前服务端并未逐阶段推送思考/工具状态，因此这里表示整次请求的处理状态，不声称能识别模型实际思考阶段。装饰层不接收鼠标事件；系统启用减少动态效果时保留静态彩虹边框。

verify-composer-ui.cjs 使用本地合成请求验证高度、贴底、输入增高、快捷键、请求成功/失败/重试、减少动态效果及窄窗口布局。verify-composer-windows.cjs 在 Windows 实际客户端发送一条不涉及业务工具的短消息，核对真实请求期间的边框及完成后的关闭行为，检查结束后删除该测试对话。结果与截图位于 desktop-client/artifacts。

仅涉及前端与桌面安装包，不修改全局提示词、有赞配置或暂停中的商品/店铺会话工作。
