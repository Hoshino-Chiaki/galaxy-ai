# 后端模块结构

本次将公共浏览器基础能力和有赞业务适配拆开，云端部署目录仍为 `/opt/galaxy-ai/backend`。现有管理 API、工具命令、权限、JSON 存储和桌面端请求方式保持兼容，无须重新安装客户端。

```text
backend/xingxu/
├── browser/                 公共基础能力，不依赖有赞
│   ├── http.py              独立 cookie 会话、限制响应大小、保留跳转供业务判断
│   ├── process.py           虚拟显示环境、私有 stdin、JSON 行事件、超时取消与进程清理
│   └── locks.py             按会话哈希互斥，不保存凭证明文
├── youzan/                  有赞业务适配
│   ├── service.py           账号连接、刷新任务、凭证加密读写和工具凭证接口
│   ├── http.py              有赞域名与跳转规则、店铺列表、进入店铺、业务 cookie 获取
│   ├── csrf.py              有赞页面 CSRF 字段解析
│   ├── sessions.py          有赞每店会话、缓存与授权店铺范围
│   ├── login.py             固定登录适配器的参数、进度、凭证结果与错误映射
│   ├── routes.py            /api/v1/admin/youzan 管理路由及管理员检查
│   ├── commands.py          有赞 CLI 参数规范化、子命令和输入校验
│   ├── tool_runtime.py      有赞单店/多店工具执行、切店、结果判定与凭证脱敏
│   ├── schemas.py           有赞管理请求模型
│   ├── constants.py         有赞 URL、状态和提示文字
│   └── __init__.py          保留 xingxu.youzan 的原有公开导入入口
├── tool_context.py          通用工具身份、执行异常、严格 JSON 解析
├── tools.py                 唯一 galaxy_cli 网关、权限审核、CLI 子进程和审计
├── app.py                   服务组合、路由挂载和公共 API
└── shop_sessions.py         原导入路径兼容层，只有转发，没有有赞实现
```

## 依赖方向

`app.py → youzan/ → browser/`。公共浏览器代码没有有赞网址、SID/CSRF 字段名、店铺切换规则或有赞权限判断。跳转到哪里、哪些 cookie 属于业务凭证、什么时候重新登录、如何选择店铺，都由有赞模块决定。公共层不接受来自模型的任意浏览器命令，也没有新增对外接口。

同一 SID 在有赞服务器绑定当前店铺，因此“进入目标店铺 → 获取该店凭证 → 执行 CLI → 校验结果”的业务顺序仍由 `youzan/` 负责；它使用公共 `SessionLocks` 实现互斥。凭证不通过命令参数或环境变量传递，仍使用服务端私有 stdin；凭证加密文件位置及内容格式不变。

工具网关保留统一身份验证、权限重新检查和审计。有赞的参数、店铺范围、读写限制、完整业务结果判定位于有赞模块，网关调用它们；Excel、文件发布和工具分类提示词的行为不变。

后续接入其他平台时，新增同级业务目录，复用 `browser/` 的会话、读取和进程能力，编写该平台自己的登录和凭证适配，并在服务组合处挂载路由、在网关注册命令及权限。它不会自动获得有赞的账号、店铺、会话或权限。

## 兼容与验证

旧的 `from xingxu.youzan import YouzanService` 和 `from xingxu.shop_sessions import ShopSessions` 仍可使用。原顶层 `youzan.py` 已替换为包目录，真实业务实现不再留在顶层。部署只传输重构所需的 Python 源码，不复制私有配置、密钥和历史浏览器登录运行时。仍暂停的商品搜索及其他商品改动没有随本次上线。

后端测试包括多用户凭证隔离、逐次切店、同 SID 互斥、权限撤销、原路由及参数兼容；公共层另有独立 cookie、跳转控制、响应大小、私有管道、超时/取消清理测试。登录适配器只用模拟事件验证协议，没有运行历史登录程序或重新登录。

飞书已按此边界新增 `xingxu/feishu/`，复用统一工具网关，官方 CLI wrapper 独立位于 `backend/feishu/`；详见《飞书模块与控制台权限.md》。
