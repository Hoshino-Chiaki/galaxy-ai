# Galaxy AI 桌面端更新

## 当前入口

- 版本信息：`GET https://124.222.51.137/api/v1/updates/latest`
- 安装包：`GET https://124.222.51.137/api/v1/updates/packages/galaxy-ai-Setup-X.Y.Z.exe`
- 服务器存储目录：`/opt/galaxy-ai/releases/`
- 命名：`galaxy-ai-Setup-X.Y.Z.exe`，例如 `galaxy-ai-Setup-0.7.9.exe`。

客户端启动 4 秒后检查；运行中每 6 小时检查。用户也可在“关于 Galaxy AI”手动检查。
使用三段整数比较版本，`0.7.10` 高于 `0.7.9`；相同版本和低版本不提示覆盖。
升级前会请求当前发布信息，通过固定的 HTTPS 服务器和随客户端打包的证书下载；不接受页面传入的下载 URL、路径和执行参数。
下载显示进度，核对精确大小、SHA-256 和 EXE 文件头；成功后才运行 NSIS 安装器。
安装到客户端原目录，并传递 `--updated --force-run`，保留原用户数据并重新打开。Windows 若要求提权仍须用户确认。
网络中断会保留与当前版本大小、SHA-256 匹配的已下载部分，自动重试并支持关闭后继续；校验失败才清除下载缓存。

## 发布流程

1. 在 `desktop-client/package.json` 与锁文件递增版本号；构建并在 Windows 验证安装包。
2. 上传命名正确的完整安装包与更新说明文本到服务器暂存目录。
3. 在服务器执行：

```bash
python3 /opt/galaxy-ai/deploy/publish-desktop.py \
  /path/to/galaxy-ai-Setup-X.Y.Z.exe \
  --notes-file /path/to/release-notes.txt
```

脚本复制安装包后，再原子更新 `latest.json`；发布无需重启服务。
同一版本已有不同内容时会拒绝发布，应使用新的版本号。
只把 EXE 放进目录不会自动发布；必须运行脚本，才能同时生成校验信息和新版本记录。
更新 API 仅提供公开客户端安装包及说明，没有上传或任意文件读取功能。

## 兼容与首次升级

早于本次更新机制的客户端需要手动安装一次带更新能力的版本，此后可在客户端内升级。
安装包不包含 AI、有赞或飞书密钥；原有业务配置保留在服务器。

## 在哪里写更新说明

每个版本单独写在项目的 `deploy/release-notes/版本号.md` 中。
例如：`deploy/release-notes/0.8.3.md`。
客户端会把二级标题显示为分组，把列表项逐条展示，支持 `**重点文字**`，不执行 HTML。
旧版本的纯文本说明仍能正常展示。

```markdown
## 新增
- 增加 **功能名称**，说明用户现在能完成什么。

## 优化
- 改善 **页面或交互**，简要说明变化。

## 修复
- 修复具体问题，说明恢复了什么行为。
```

写完之后把文件上传到服务器，例如 `/opt/galaxy-ai/releases/notes-0.8.3.md`，并重新运行发布脚本：

```bash
python3 /opt/galaxy-ai/deploy/publish-desktop.py \
  /opt/galaxy-ai/releases/galaxy-ai-Setup-0.8.3.exe \
  --notes-file /opt/galaxy-ai/releases/notes-0.8.3.md
```

单独修改说明文件不会自动生效；发布脚本会把它写入 `latest.json`。
只改当前版本的更新说明时，可以用原安装包重新发布，不必重新构建安装包。

## 下载速度

当前采用服务器 HTTPS 直传，下载器保留单连接和连接复用。
2026-11-18 在 Windows 上测试，单连接短测约 460 KiB/s，四路并发合计约 270 KiB/s；当时服务器总出口约 380 KiB/s。
这些是当时链路的实测值，不代表服务器套餐标称带宽。约 128 MiB 的完整安装包仍需数分钟。
下载器显示已下载大小、速率和预计剩余时间，网络中断后继续下载；这些功能需要安装 0.8.3 或更新版本后生效。
若需要明显提高完整包的传输速率，需要调整服务器公网带宽或接入分发服务。
