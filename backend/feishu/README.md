# Galaxy AI 飞书 CLI

官方源码：<https://github.com/larksuite/cli>，固定 commit 见 `cli/upstream.commit`，MIT 许可保存在 `cli/UPSTREAM-LICENSE`。

`cli/main.go` 通过官方 `extension/credential` 提供私有 stdin 凭证源。普通业务只使用当前员工的用户身份；`attendance/user_tasks/query` 使用经服务器核验员工范围的应用身份。两种 token 类型不能互换，不使用环境变量或公用 CLI 登录缓存保存凭证。官方 `platform.Restrict` 和固定命令目录共同限制入口，Galaxy Python 工具再逐项校验参数，不提供任意命令、通用 API 或 shell。

运行文件是 `bin/lark-cli`，仅部署在服务器；不放进桌面安装包。

构建：在此项目中执行 `backend/feishu/cli/build.sh`，需要 Git、Go 和依赖网络。脚本仅在临时目录取固定源码，不改官方项目，不安装其 Agent Skills，不处理账号授权。构建完成后将 `bin/lark-cli` 与此目录一同部署。

OAuth、刷新和员工加密凭证由 `backend/xingxu/feishu/` 管理，个人连接使用官方设备授权协议。应用身份凭证由服务器按应用版本缓存并更新，只有已登记的考勤操作可以取得。网关只将本次操作获准使用的短期访问 token 和应用 ID 交给 CLI，不向 CLI 传 App Secret 或 refresh token。
