# Galaxy 工具执行权限

当前模型侧只开放 `galaxy_cli` 这一个函数工具，参数为 `{"args":["help"]}`。实际执行由 Arch 聊天后端完成。管理员和员工都使用同一个执行边界；已授权只读的 `help` 和 `youzan.customer-search`，模型仍只有一个函数入口。

## 执行流程

1. 登录会话验证成功后，服务器生成执行上下文，包含用户 ID、工作空间、权限和对话 ID。
2. 向模型声明唯一函数 `galaxy_cli`。模型生成的普通文本、代码块或命令说明仅作为回复展示，不触发执行。
3. 收到结构化工具调用后，服务器重新校验原登录会话和用户身份，检查 `tools:galaxy_cli` 权限。
4. 工具名精确匹配 `galaxy_cli`；参数必须只有 `args` 字段，命令必须出现在服务端命令授权表。`help` 需要 `galaxy:help`；`youzan.customer-search` 需要 `youzan:customer:read`。
5. 校验成功后，固定启动项目 `galaxy-cli/.venv/bin/galaxy-cli`。使用参数数组直接创建进程，不经过 Shell。
6. CLI 输出的 JSON 回给模型，模型继续生成最终回复。界面记录该调用为已完成、已拒绝或执行失败。

`help` 支持读取全部目录或查询一个格式合法的工具名，输出统一为 JSON。新增 CLI 工具会自动出现在目录中，执行权限需要另行登记和授予；注册不会自动扩大 AI 权限。

## 强制边界

- 模型没有程序路径、Shell、解释器、工作目录、环境变量、stdin 或用户身份的设置入口。
- 伪造 `bash`、`python`、`exec` 等函数调用会被拒绝；在 `galaxy_cli` 参数中夹带这些命令也会被拒绝。
- `--input` 只接受对应工具的公开 Schema。客户搜索仅接受已声明的业务筛选；token、SID、user_id、店铺、URL、环境等额外字段会在启动进程前拒绝。
- 每次执行前重新验证会话；排队取得执行名额后再次检查命令权限。已注销、停用、身份不符或权限已撤销的请求不会启动 CLI。
- CLI 的 HOME、XDG 配置目录按服务器用户 ID 分开，位于 `private/cli-users/<user_id>/`，目录权限为 `0700`。
- 子进程只获得明确指定的最小环境，不继承供应商 API Key、登录会话 token、PYTHONPATH 等服务器环境。
- help 最长 10 秒，业务查询最长 40 秒；stdout 与 stderr 总计最多 256 KiB，同时最多执行 8 个进程。
- 工具调用不设业务轮数、总次数、单批数量或整轮时长硬限制；执行策略由管理员的全局提示词决定。身份鉴权、命令权限、参数结构和账号隔离仍由服务器执行。
- 新命令须在 `COMMAND_PERMISSIONS` 中定义所需权限，再由身份权限表授予对应角色。

这是模型调用入口、参数及命令权限边界。CLI 工具代码是服务器信任的实现，当前没有部署独立操作系统沙盒；后续业务工具仍需落实各自的数据权限和第三方凭证隔离。

## 记录与模型上下文

`private/tool_audit.json` 记录调用 ID、用户和工作空间、对话、标准化命令、状态、错误类别及耗时。执行前先写入 pending 记录，无法写入时不执行；结束后更新结果。审计不保存原始模型参数、token、环境或输出原文。

聊天记录中的 `tool_events` 保存调用结果，供本人在界面查看。底层模型协议消息保存在内部 `model_context`，不通过会话读取接口返回。对话归属检查与原有聊天一致，管理员不能据此读取员工私人对话。

思考模式下的工具连续调用按供应商协议保留必要的 `reasoning_content` 与 tool_call_id，在后续请求中回传；思考文本独立于最终答案。DeepSeek 对工具模式的要求参见 [Thinking Mode](https://api-docs.deepseek.com/guides/thinking_mode/)。

## 当前与后续

当前用已有产品登录会话进行服务端校验。用户确定的“登录后向 CLI 下发权限令牌、CLI 自动携带令牌访问工具服务”仍是后续独立功能，目前不会将产品会话 token 交给 CLI 或模型。

CLI 可独立运行 `galaxy-cli help` 查看公开工具目录。该终端功能与模型工具入口分开；已增加有赞客户搜索业务命令，尚未实现 MCP 协议服务。

## 验证

`tests/test_tools.py` 覆盖唯一工具声明、固定进程与环境、命令／参数注入、身份伪造、注销与权限撤销、执行前审计、超时与输出限制、上下文恢复及超过旧轮数/次数后的持续调用。模拟越权模型回复时检查没有启动进程，而不只是检查错误提示。

## youzan 分类凭证

有赞连接由服务器的用户 ID 与 workspace 共同定位。手动刷新 CRM 时，正常进入当前所选店铺，取得新的 CRM CSRF 与店铺业务 token，再用现有 Fernet 密钥加密保存。重新签发 SID、更换账号／密码或店铺会清除不再匹配的分类凭证。

执行 `youzan.customer-search` 时，网关在权限检查及取得执行名额后读取本人凭证，通过 stdin 管道传给固定 CLI 的分类上下文。只有业务筛选出现在 argv 中；产品 token、SID、CSRF、业务 token 和供应商 Key 不进入 argv、环境、审计或模型上下文。子进程结果经过分类凭证值脱敏；完成时再次检查登录、命令权限及店铺／会话是否变化，连接已切换则不返回旧结果。

未绑定有赞的员工不会借用管理员连接。员工的配置页面权限与业务查询权限独立；当前员工可调用查询命令，但未绑定自己的可用连接会明确拒绝。分类名称不构成授权。分店筛选读取有赞的数据权限接口，并拒绝列表外 ID 和不唯一的名称。

`GET /api/v1/admin/ai/tools` 要求管理员 AI 配置权限，通过同一个调度器实际执行 help，返回 CLI JSON 供工具列表页原样展示。该接口不读取分类凭证。

## 输出

help 每项仅有工具名、分类、描述。业务命令直接返回有赞接口完整 JSON，保留全部业务字段及原始结构和值，不做字段裁剪或空值过滤。仅分类凭证原值继续脱敏。内部校验、执行权限、用户隔离和审计继续执行。
